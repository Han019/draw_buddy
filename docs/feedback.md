# DrawBuddy 개선 사항 피드백 (Feedback)

## 1. 개선 된 것 (Resolved)

### 1.1 Lobby 화면 개선 (`RoomScreen.tsx`, `LobbyScreen.tsx`)
- **초대 링크 복사 튕김 버그 수정:** '초대 링크' 버튼이 `<a>` 태그로 되어있어 페이지가 새로고침되며 튕기던 문제를 수정했습니다. (이제 안전하게 복사 기능만 동작합니다.)
- **준비 상태 시각화:** 대기실 플레이어 목록에서 'Waiting / Ready' 텍스트 대신 직관적인 초록색 불빛(Indicator)이 점등되도록 UI를 개선했습니다.
- **설정 창 변경:** Game Settings에서 불필요해진 'Rounds'를 완전히 제거하고 'Write Time(글 작성 시간)'을 설정할 수 있도록 연동을 마쳤습니다.

### 1.2 Prompt 화면 개선 (`PromptScreen.tsx`)
- **IDE 문법 에러 및 프롭스 연동 수정:** `GameScreen.tsx`에서 넘겨주던 `defaultText`, `timeLimit`, `onCancel`, `isSubmitted` 프롭스들을 `PromptScreen.tsx`가 정상적으로 처리하도록 인터페이스를 최신화했습니다. (이로 인해 발생하던 빨간 줄 에러가 해결되었습니다.)
- **제출 토글 버튼 정상화:** 제출 후 버튼이 "제출 취소"로 바뀌며 상태를 취소할 수 있도록 `isSubmitted` 상태에 따른 상호작용 잠금 기능을 복구했습니다.

### 1.3 TypeScript 및 타입 에러 완벽 해결 (`api.ts`, `RoomScreen.tsx`)
- **타입 정의 최신화:** 백엔드 모델 변경사항에 맞춰 프론트엔드의 `api.ts` 파일 내 `Room` 인터페이스에 `draw_time`, `write_time` 필드를 명시적으로 추가하고, `RoomPlayer` 인터페이스에 `avatar_url` 필드를 추가했습니다.
- **우회 코드 제거:** 타입 정의가 일치함에 따라 `RoomScreen.tsx`에서 임시로 사용하던 `(room as any)` 형태의 타입 캐스팅을 모두 제거하고 원래의 깔끔한 코드로 복구했습니다. 이제 IDE에서 더 이상 빨간색 오류가 뜨지 않습니다.

### 1.4 Drawing / Result 화면 개선 (`DrawingScreen.tsx`, `ResultScreen.tsx`)
- **Drawing 상호작용 및 UI 수정:** Safari 환경에서 깨지던 컬러 피커를 원형 무지갯빛 UI로 수정했으며, 타이머 옆에 제출 인원 현황을 추가했습니다. 제출 토글 기능도 적용했습니다.
- **Result 화면 프로필 및 슬라이드 동기화:** 최상단 프로필 원 잘림 현상을 수정하고 말풍선 및 결과 뷰에 프로필 이미지가 노출되도록 반영했습니다. 방장이 슬라이드를 넘기면 다른 유저들의 화면도 동기화되도록 웹소켓 이벤트를 연결했습니다. 마지막 화면에서는 대기실/홈 이동 버튼이 분기 노출됩니다.

### 1.5 디스코드 연동 프로필 이미지 표시 (백엔드 버그 수정)
- **해결 완료:** 프론트엔드와 `serializers.py`에는 `avatar_url` 연동이 잘 되어있었으나, 유저가 방을 생성(`RoomCreateAPIView`)하거나 참가(`RoomJoinAPIView`)할 때 `RoomPlayer` DB에 `discord_user` 외래키를 연결해주지 않는 백엔드 누락 버그가 원인이었습니다. `views.py`를 수정하여 정상적으로 아이콘이 나타나도록 구현을 완료했습니다.

### 1.6 결과 화면에서 대기실로 정상 복귀 기능 추가 (`RoomSettingsAPIView`, `ResultScreen.tsx` 등)
- **해결 완료:** 기존에는 대기실로 돌아가기 버튼이 `onExit(나가기)` 기능을 호출하여 방 자체에서 나가지는(홈으로 이동하는) 문제가 있었습니다. 이를 해결하기 위해 백엔드의 방 설정 API에 `status`를 `waiting`으로 초기화하는 기능을 추가하고, 방장이 대기실로 복귀 시 게임 참가자들의 모든 준비 상태(`is_ready`)를 해제한 뒤 웹소켓을 통해 모두 동시에 대기실로 돌아가도록 연동했습니다.

## 2. 개선 해야할 것 (To Be Resolved)

### 2.1 방 나가기 잔상 문제 & 방장 위임 불가 이슈 (백엔드 웹소켓)
- **원인:** 현재 방을 나갈 때 실행되는 API(`POST /leave/`)는 정상적으로 DB에서 유저를 삭제하지만, 남아있는 사람들에게 "누군가 나갔다"는 실시간 알림(웹소켓 이벤트)을 백엔드에서 쏴주지 않기 때문에 화면이 바로 갱신되지 않는 현상입니다. 
- **해결 방법:** 백엔드 `views.py`의 `RoomLeaveAPIView` 안에서, 플레이어 DB 삭제 후 `channel_layer.group_send`를 통해 `room_updated` 이벤트를 강제로 브로드캐스트하도록 파이썬 코드를 수정해야 완벽하게 해결됩니다. 

### 2.2 3명 이상 게임 진행 정지(무한 대기) 현상
- **원인:** 현재 게임 턴 전환 로직은 `turn_manager.py`에 있습니다. 3명 이상일 경우 백트래킹 알고리즘으로 A->B->C 서로 안 겹치게 턴을 잘 배정하도록 짜여 있습니다.
- **문제 발생 케이스:** 한 명이라도 네트워크 문제로 튕겼거나, "제출(Submit)"을 누르지 않은 상태라면 서버는 **"모든 플레이어가 제출할 때까지"** 다음 턴을 내주지 않고 무한정 기다리게 됩니다.
- **해결 방법:** 특정 턴의 제한 시간이 지나면 미제출자의 턴을 강제로 '자동 제출(Auto Submit)' 시켜버리는 처리가 백엔드 로직에 추가되어야 합니다. 그래야 게임이 중간에 멈추는(Freezing) 현상을 완벽히 방지할 수 있습니다.
